### About

Full-stack developer and founder of **[Achomi Tech](https://achomi.net)**, a studio

last pixel of the interface.

- I work across the whole stack: front end, back end, database, deployment

- Open to client work and collaboration — **[get in touch](mailto:team@achomi.net)**
